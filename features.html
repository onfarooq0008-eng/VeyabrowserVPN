Features

A complete everyday browser that stays small, quick and private.

Privacy & security

  • Ad & tracker blocker using EasyList and EasyPrivacy, with an on-screen counter of blocked requests and per-site controls.
  • Private tabs in a separate WebView profile (where Android supports it): cookies, storage and cache are isolated and wiped when the last private tab closes.
  • Third-party cookie blocking, optional Do Not Track and Global Privacy Control signals, and clear-data-on-exit.
  • Per-site permissions: websites must ask before using your camera, microphone or location, and you choose each time.
  • Warnings for pages with invalid security certificates and a safer download check before files are opened.
  • Optional app lock using your device screen lock.

Built-in VPN

  • Optional WireGuard VPN inside the app: pick a server, see ping times, connect with one tap.
  • Browser traffic only mode protects Veya without routing other apps through the VPN.
  • Nothing is routed through the VPN until you turn it on and approve Android’s VPN permission. More about the VPN.

Tabs

  • Unlimited tabs, each with its own independent session and scroll position.
  • Tab switcher with search, grid or list layout, swipe-to-close and an active-tab highlight.
  • Tab groups: create, rename, filter and delete groups without losing the tabs inside.
  • Recently closed list and session restore (tabs, groups and the tab you were on).
  • Smart memory management: inactive background tabs are unloaded to save RAM and reload when you open them.

Video & media

  • Built-in video player for web videos, including HLS and DASH streams, with swipe gestures for brightness, volume and seeking, double-tap to skip and hold for 2× speed.
  • Floating player (picture-in-picture) using Android’s native PiP window, with play/pause and a Back-to-browser button.
  • Playback speed, background audio option and a “Play in player” button when a video is found on a page.
  • Websites that block PiP or full screen are respected — Veya does not bypass DRM or content protection.

Downloads

  • Download manager with pause, resume, retry and notifications, using several connections for speed.
  • Files are saved in the “Veya” folder in your Downloads and can be opened or shared from the app.
  • Support for files that only exist inside the page (blob links).

Everyday tools

  • Search with Google, Bing, DuckDuckGo, Ecosia, Brave, Yahoo or a custom engine; search suggestions can be switched off.
  • QR code scanner, voice search, find in page, read aloud, page translate and night mode.
  • Home page with round shortcuts, bookmarks, history, and a customisable wallpaper.
  • Desktop-site mode, text size, user scripts and an element hider (“Mark as ad”).
  • Set as default browser to open links from other apps.
Features can vary by Android version and device. Some websites restrict full-screen video or picture-in-picture; Veya will tell you when a site does not allow it.
